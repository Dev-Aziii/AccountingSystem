# Document Numbering Manual Migration Guide (Package Manager Console)

> This guide is for the developer to run manually. No migrations were generated by Codex.

## 1) Add/verify model changes in code
- `DocumentSequence` entity exists with:
  - `CompanyId`
  - `DocumentType` (string-converted enum)
  - `Prefix`
  - `NextNumber`
  - `RowVersion` concurrency token

## 2) Create migration manually in PMC
```powershell
Add-Migration AddDocumentSequencesAndDocumentReferences -Project AccountingSystem.Api -StartupProject AccountingSystem.Api
```

## 3) Review generated migration
Ensure it includes at least:
- `DocumentSequences` table
- Unique index: `(CompanyId, DocumentType)`
- RowVersion/timestamp column for concurrency
- Bill fields:
  - `VendorReferenceNumber`
  - `SystemReferenceNumber`
- Invoice field:
  - `ReferenceNumber`

## 4) Apply migration in PMC
```powershell
Update-Database -Project AccountingSystem.Api -StartupProject AccountingSystem.Api
```

## 5) Seed/verify numbering defaults per company
Run app and open:
- **Admin > Company Settings > Document Numbering**

Validate defaults:
- Invoice: `INV-` starting `1`
- Journal Entry: `JE-` starting `1`
- Payment Received: `PR-` starting `1`
- Check Payment: `CHK-` starting `1`

## 6) Post-migration smoke checks
- Create invoice and confirm generated reference: `INV-####`
- Post journal entry and confirm generated reference: `JE-####`
- Receive customer payment and confirm generated reference: `PR-####`
- Pay bill/check and confirm generated reference: `CHK-####`
- Confirm vendor bill still accepts manual vendor invoice number.
